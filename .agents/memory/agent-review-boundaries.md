---
name: Agent review boundaries
description: The user's chosen separation of responsibilities for engineering-agent reviews.
---

Independent review agents must not edit specialist-owned files. They report findings and request changes; the specialist who owns the deliverable makes the revisions.

**Why:** The user chose read-only reviewers to preserve independent review and clear ownership.

**How to apply:** Keep review work read-only. Route each requested change to the responsible specialist, and require a fresh review after revisions before release.
