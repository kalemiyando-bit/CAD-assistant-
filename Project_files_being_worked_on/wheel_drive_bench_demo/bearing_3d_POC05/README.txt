WHEEL DRIVE BENCH DEMONSTRATOR — BEARING ENVELOPE POC-05
3D-ONLY PART SPECIFICATION

This folder contains one preliminary annular-cylinder bearing envelope. It is
not a detailed rolling-element bearing model, a selected supplier part, or an
assembly.

PRELIMINARY ENVELOPE

- Outside diameter: 12 mm
- Inside diameter: 6 mm
- Axial width: 4 mm
- Axis: global +Y in a right-handed Z-up part coordinate system
- Datum: center of the base annular face at the part origin

The dimensions are carried forward from the preliminary A0 concept and are
assumptions. They do not specify bearing type, load/speed rating, tolerance,
fit, lubrication, or sealing.

This specification passed local schema validation with the full seven-part
set. Per the user's direction, include it in the combined Fusion verification
after all planned parts have been created. Use the existing
`generate_fusion_model` 1.3.0 script; it saves to the configured default
output folder without asking for a folder on each run.
