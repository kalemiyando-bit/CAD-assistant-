# Mesh formats

This folder contains the three parts and a combined positioned assembly as **STL** and **3MF**.

- STL is a triangle mesh with no feature tree or analytic surface history.
- 3MF is also a mesh format; it can preserve print-oriented metadata, but it is not a parametric SolidWorks part.
- The assembly mesh combines the positioned component triangles and does not preserve native part relationships or mates.

Use these files only to compare mesh import, preview, or print workflows. For editable CAD geometry, prefer the native macro output or the STEP files.
