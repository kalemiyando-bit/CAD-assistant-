# DXF 2D references

The DXF files are millimetre-based 2D references:

- `SpurGear_18T_Module2_profile.dxf` — gear outline, bore, and pitch/root reference circles.
- `Wheel_OD80_Hub30_views.dxf` — wheel front and side outlines.
- `Shaft_12x100_views.dxf` — shaft side and end outlines.
- `GearWheelShaftDemo_assembly_layout.dxf` — axial side layout of the three components.

DXF can be imported as sketch or drawing geometry in SolidWorks. These are reference outlines, not complete manufacturing drawings: they omit tolerances, material specifications, fits, and validation notes.
